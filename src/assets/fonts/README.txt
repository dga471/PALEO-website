Web fonts used by the site, self-hosted so that visitors are not sent to a
third-party font service.

- Newsreader (headings), by Production Type. SIL Open Font License 1.1.
  https://fonts.google.com/specimen/Newsreader
- Source Sans 3 (text), by Adobe. SIL Open Font License 1.1.
  https://fonts.google.com/specimen/Source+Sans+3

The files are the "latin" and "latin-ext" subsets of the variable fonts as
served by Google Fonts. They are declared in src/styles/tokens.css.
